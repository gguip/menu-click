# Fontes

`sora-latin.woff2` é a Sora (Sora Project Authors), variável nos pesos 100 a
800, no recorte latino do Google Fonts — o que cobre o português. Licença SIL
Open Font License 1.1 (https://openfontlicense.org), que permite distribuir o
arquivo junto do app.

O arquivo fica no repositório de propósito: com `next/font/google` o build
baixava a fonte do Google a cada vez, e uma falha dessa ida derrubava o CI.
